## 🏃 The idea

It's **8:40**. Wake up, breakfast, brush teeth, get dressed… and the school gate closes at **9:00**. **School Rush** turns that daily morning race into a game: mum or dad run from home to school with the kids behind them through the streets of **San Sebastián de los Reyes** and **Alcobendas** (near Madrid), dodging Lego bricks, cats, puddles, pigeons… and a runaway bull from the town's bull run, while the clock keeps ticking.

### In 30 seconds

- 👩‍👧‍👦 **Pick who takes the kids**: mum or dad.
- 🦘 **Jump** (double jump in the air) and **duck** to dodge.
- 🏠➡️🎉➡️🚇➡️🏫 **Four stretches in a row**: home, Sanse during its fiestas, Alcobendas and school.
- 🪥🚦🚪 **Three quick moments**: teeth, traffic light and the closing gate.
- 🍞 **Toast** for points and **streaks** up to x5.
- 🛴☂️☕ **Power-ups**: scooter, umbrella and coffee.
- 👕 **Dress the kids** with their name, hairstyle and accessories.
- 🎁 **8 challenges** that unlock sunglasses, a crown, a hero cape…
- ⭐ **Arrive by 8:58** for three stars.

## 👨‍👩‍👧 For families

| | |
| --- | --- |
| 👶 **Age** | Everyone. Little ones get it in one run thanks to the tutorial; older players chase 3 stars and the challenges |
| ⏱️ **Length** | Just over **1 minute** per run: perfect for "one more and we go" |
| 😌 **No frustration** | Nobody loses halfway: hits only add minutes, you always reach school |
| 🚫 **No ads or purchases** | No accounts, no sign-ups, nothing to pay |
| 🔇 **Mute** | 🔇 button to play silently |
| 📱 **Where** | Phone or tablet (landscape: full screen with floating buttons; portrait: huge buttons below), or a computer with the keyboard. Installable as an app that **works offline** |

<a id="play"></a>

## 🎮 How to play

| | 💻 Computer | 📱 Phone or tablet |
| --- | --- | --- |
| **Jump** | `Space` or `↑` | Orange **⬆ SALTAR** button (or tap the screen) |
| **Double jump** | Press again in the air | ⬆ again in the air |
| **Duck** | Hold `↓` | Hold the purple **⬇ AGACHAR** button |
| **Fast fall** | `↓` in the air | ⬇ in the air |
| **Moments** | `Space` | Any button or the screen |

The first time, a **slow-motion tutorial** shows *¡SALTA!* (jump) and *¡AGÁCHATE!* (duck) right when you need it.

| Situation | What happens |
| --- | --- |
| You hit something | **+1 min**, sudden stop, dizzy eyes 😵, streak lost |
| A kid trips | Stars spin over their head and **you slow down** until they catch up |
| You dodge an obstacle | **+5 points** × streak |
| You grab a toast 🍞 | **+10 points** × streak |
| Every 8 toasts in a row | Streak goes up: **x2, x3, x4, x5** |

| Stretch | ⬆️ Jump over | ⬇️ Duck under |
| --- | --- | --- |
| 🏠 Home | Lego, bouncing ball, the cat, laundry basket | Washing line (underpants in the face!) |
| 🎉 Sanse | **The bull** 🐂, bull-run fences, puddles, dogs, prams | Pigeons |
| 🚇 Alcobendas | Puddles, dogs, bins, prams | Pigeons and the scaffolding |
| 🏫 School | Footballs, puddles, prams | Pigeons |

| Power-up | Lasts | Effect |
| :---: | :---: | --- |
| 🛴 **Scooter** | 5 s | 40 % faster and you **smash through everything** |
| ☂️ **Umbrella** | 8 s | You **glide** down: huge jumps |
| ☕ **Coffee** | 6 s | **Turbo**: 28 % faster, so you arrive earlier |

| Arrival | Result |
| --- | --- |
| **8:58 or earlier** | ⭐⭐⭐ |
| **8:59 – 9:00** | ⭐⭐ |
| **After 9:00** | ⭐ |

## 👕 The kids

<p align="center"><img src="docs/img/peques.png" alt="Kids editor" width="80%"></p>

You can type **your school's name** (it appears on the gate and when you arrive), and each kid has a **name**, the **school uniform** (black jumper with polo collar, and green tartan skirt or grey trousers), **hairstyle** (pigtails, long or short), **hair colour**, **T-shirt**, **backpack** and an **extra**. Anything with a 🔒 is unlocked by a challenge:

| Challenge | Prize |
| --- | --- |
| Reach school for the first time | 😎 Sunglasses |
| Arrive with 3 stars | 🐱 Cat ears |
| Get a x5 streak | 👑 Crown |
| Grab 100 toasts in one run | 🧢 Cap |
| Beat the traffic light in under 0.35 s | 🦸 Hero cape |
| Use all 3 power-ups in one run | ✨ Golden T-shirt |
| Score 3,000 points | 💙 Blue hair |
| Arrive without a single hit | 🌈 Rainbow backpack |

<a id="privacy"></a>

## 🔒 Privacy

| | |
| --- | --- |
| **What is stored** | Who takes the kids, the school name, each kid's name and look, challenges, best score, tutorial seen, mute setting |
| **Where** | Only in the browser's `localStorage` on that device. Nothing is sent to any server |
| **What it doesn't do** | No cookies, no analytics, no ads, no trackers |
| **Fonts** | Bundled with the site (`fonts/`): no requests to Google |

<a id="tech"></a>

## 🛠️ Under the hood

Vanilla HTML, CSS and JavaScript **with no dependencies or build step** (one page, one stylesheet and eleven topic scripts in `web/`), drawing on a 960 × 540 `<canvas>` scaled to the screen.

| Part | How it works |
| --- | --- |
| **World** | A 30,000-unit run: home up to 9,000, Sanse up to 17,100, Alcobendas up to 24,000, school to the end. Speed rises from 330 to 500 per second |
| **Clock** | Starts at 8:40 and moves one minute every 5.5 s; hits and failed moments add minutes |
| **Physics** | Gravity, jump and double jump with input buffering; ducking mid-air makes you fall fast; the umbrella lowers gravity |
| **Characters** | Vector drawings animated every frame: run cycle, squash and stretch, blinking, shading and ground shadows |
| **Backgrounds** | Each stretch is painted **once** into large layers that are then just scrolled at different speeds (parallax), so it runs smoothly on phones |
| **Sound** | Music and effects synthesised with Web Audio: no audio files |

```bash
git clone https://github.com/serbenda/school-rush.git
cd school-rush
python3 -m http.server 8000 -d web
# open http://localhost:8000

# tests (play a whole run on desktop and phone)
pip install playwright && playwright install chromium
python3 tests/humo.py

# README screenshots (Playwright + ffmpeg)
python3 scripts/capturas.py
```

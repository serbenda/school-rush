# 🏫⏰ School Rush — ¡Que llegamos tarde!

Juego en pixel art estilo Jetpack Joyride (HTML + JavaScript): mamá o papá, con una mochila-cohete, llevan a los peques al cole antes de que suene la campana de las 9:00. Mantén pulsado para volar.

1. 🏠 Nivel 1 · La casa: despertar a los peques volando por encima de sus camas y coger el desayuno
2. 🧼 Asearse (dientes, cara y pelo)
3. 👕 Vestirse
4. 🚗 En coche (¡ojo con la gasolina!)
5. 🚶 Nivel 2 · La calle: esquivar coches, autobuses, semáforos y palomas
6. 🏫 Entrada al cole

Se juega con ratón, teclado o pantalla táctil. Un solo `index.html`, sin dependencias.
Se publica solo en GitHub Pages con cada push a `main` (`.github/workflows/pages.yml`).

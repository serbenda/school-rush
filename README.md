# 🏫⏰ School Rush — ¡Que llegamos tarde!

Juego de plataformas en pixel art (HTML + JavaScript): mamá o papá corren para llevar a los peques al cole antes de que suene la campana de las 9:00.

1. 🏠 Nivel 1 · La casa (plataformas): despertar saltando en las camas y recoger el desayuno
2. 🧼 Asearse (dientes, cara y pelo)
3. 👕 Vestirse
4. 🚗 En coche (¡ojo con la gasolina!)
5. 🚶 Nivel 2 · La calle (plataformas)
6. 🏫 Entrada al cole

Se juega con ratón, teclado o pantalla táctil. Un solo `index.html`, sin dependencias.
Se publica solo en GitHub Pages con cada push a `main` (`.github/workflows/pages.yml`).

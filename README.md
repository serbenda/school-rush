# 🏫⏰ School Rush — ¡Que llegamos tarde!

Juego en HTML + JavaScript: llevar a los peques al cole antes de que suene la campana de las 9:00.

1. ⏰ Despertarlos
2. 🥣 Desayuno
3. 🧼 Asearse (dientes, cara y pelo)
4. 👕 Vestirse
5. 🚗 Tráfico (¡ojo con la gasolina!)
6. 🏫 Entrada al cole

Se juega con ratón, teclado o pantalla táctil. Un solo `index.html`, sin dependencias.
Se publica solo en GitHub Pages con cada push a `main` (`.github/workflows/pages.yml`).
